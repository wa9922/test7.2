================================================================
           AGC 시스템 전체 구성도
================================================================

┌─────────────────────────────────────────────────────────────┐
│                     입력: Traffic Type + SNR                  │
│                (lowpowersignal/highperformancesignal, 5~20dB) │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│              1. Signal Generator (송신단)                     │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ STF (128 bits) + LTF (64 bits) + Signal Field (48)   │  │
│  │          + Payload (1024 bits)                        │  │
│  │                                                        │  │
│  │ Preamble: BPSK (고정)                                  │  │
│  │ Payload: BPSK/QPSK/16-QAM (MCS 선택)                  │  │
│  └───────────────────────────────────────────────────────┘  │
│                    Clean Signal (I+jQ)                       │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│              2. AWGN Channel (채널)                          │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ Noise Power = Signal Power / SNR_linear               │  │
│  │ Noisy Signal = Clean Signal + Noise                  │  │
│  └───────────────────────────────────────────────────────┘  │
│                    Noisy Signal                              │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│         3. AGC FSM (수신단 - 자동 이득 제어)                  │
│                                                              │
│  [IDLE] → [DETECT] → [COARSE_AGC] → [TRACK] → [IDLE]       │
│    ↑                                             │           │
│    └─────────────────────────────────────────────┘           │
│                                                              │
│  ┌────────────── DETECT 상태 ──────────────┐                │
│  │ Carrier Sensing (패킷 감지)              │                │
│  │ ┌──────────────────────────────────┐   │                │
│  │ │ • Energy Detection               │   │                │
│  │ │ • Correlation Detection          │   │                │
│  │ │ • Saturation Detection           │   │                │
│  │ └──────────────────────────────────┘   │                │
│  │ → 감지 실패: IDLE 복귀                 │                │
│  │ → 감지 성공: COARSE_AGC 진행           │                │
│  └──────────────────────────────────────┘                │
│                                                              │
│  ┌────────── COARSE_AGC 상태 ──────────┐                    │
│  │ STF Power 측정 → Gain 결정          │                    │
│  │ ┌────────────────────────────────┐ │                    │
│  │ │ STF Power (dBFS) 측정          │ │                    │
│  │ │ Target: -10 dBFS               │ │                    │
│  │ │ Error = Target - Measured      │ │                    │
│  │ │ Gain Adjustment: ±3 dB step    │ │                    │
│  │ │ Gain Range: 10~50 dB           │ │                    │
│  │ └────────────────────────────────┘ │                    │
│  │ ✅ Gain 결정 완료 (이후 고정)        │                    │
│  └──────────────────────────────────┘                    │
│                                                              │
│  ┌────────────── TRACK 상태 ────────────┐                   │
│  │ Gain 고정, 패킷 수신                  │                   │
│  │ • LTF: Power 측정만 (조정 안 함)     │                   │
│  │ • Signal Field: 트래픽 타입 디코딩   │                   │
│  │ • Payload: 데이터 수신               │                   │
│  └──────────────────────────────────┘                   │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│              4. RF Front-End (아날로그)                       │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  UnifiedRFPath (모든 모델 동일)                        │  │
│  │  ┌────┐    ┌─────┐    ┌────┐    ┌────┐              │  │
│  │  │LNA │ → │Mixer│ → │VGA │ → │LPF │              │  │
│  │  │15dB│    │     │    │가변│    │    │              │  │
│  │  └────┘    └─────┘    └────┘    └────┘              │  │
│  │                                                        │  │
│  │  Total Gain = LNA(15) + VGA(variable) = 10~50 dB     │  │
│  │  Power: 392 mW (고정, MAX2829 모델)                   │  │
│  └───────────────────────────────────────────────────────┘  │
│                 Amplified Signal                             │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│              5. ADC + Digital Processing                     │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 1단계: 10-bit ADC (항상)                              │  │
│  │        Range: -512 ~ 511                              │  │
│  │        Levels: 1024                                   │  │
│  │                                                        │  │
│  │ 2단계: Digital Truncation                             │  │
│  │   ┌─────────────────────────────────────┐            │  │
│  │   │ Fixed Low Power:    5-bit (고정)    │            │  │
│  │   │ Fixed High Perf:    10-bit (고정)   │            │  │
│  │   │ Adaptive (제안):    5 or 10-bit     │            │  │
│  │   │   - lowpowersignal:  5-bit          │            │  │
│  │   │   - highperformancesignal: 10-bit   │            │  │
│  │   └─────────────────────────────────────┘            │  │
│  └───────────────────────────────────────────────────────┘  │
│                 Quantized Signal                             │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│              6. Signal Field Decoding                        │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ BPSK 복조 → Traffic Type 추출                         │  │
│  │ "01" → lowpowersignal                                 │  │
│  │ "10" → highperformancesignal                          │  │
│  │                                                        │  │
│  │ Adaptive 모델만:                                       │  │
│  │   Digital Bits 재선택 (5 or 10)                       │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│              7. BER Calculation (성능 평가)                   │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ STF BER: Reference STF bits와 비교                    │  │
│  │ Packet BER: 전체 패킷 복조 후 비교                    │  │
│  │                                                        │  │
│  │ Hard Decision BPSK/QPSK/16-QAM                        │  │
│  │ Error Count / Total Bits                              │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│              8. Power Measurement (전력 평가)                 │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ Analog Power (모든 모델 동일):                        │  │
│  │   392 mW × duration = Energy (mJ)                     │  │
│  │                                                        │  │
│  │ Digital Power (비트 수에 비례):                        │  │
│  │   Operations × Area Scaling = Energy (pJ)            │  │
│  │   5-bit:  93 μm² (낮은 전력)                          │  │
│  │   10-bit: 362 μm² (높은 전력)                         │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                   9. 결과 수집                               │
│  • BER (Bit Error Rate)                                     │
│  • Analog Energy (mJ)                                       │
│  • Digital Energy (pJ)                                      │
│  • Latency (ms)                                             │
│  • Final Gain (dB)                                          │
│  • Operations (Additions, Multiplications)                  │
└─────────────────────────────────────────────────────────────┘

================================================================
           세 가지 AGC 모델 비교
================================================================

┌────────────────────────────────────────────────────────────┐
│  1. Fixed Low Power AGC (종래 방식 1)                       │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ • Digital Bits: 5-bit (고정)                         │  │
│  │ • Gain: AGC 자동 조절 (STF 기반)                    │  │
│  │ • 장점: 낮은 디지털 전력 (93 μm²)                   │  │
│  │ • 단점: 높은 BER (정확도 낮음)                      │  │
│  └──────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│  2. Fixed High Performance AGC (종래 방식 2)                │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ • Digital Bits: 10-bit (고정)                        │  │
│  │ • Gain: AGC 자동 조절 (STF 기반)                    │  │
│  │ • 장점: 낮은 BER (정확도 높음)                      │  │
│  │ • 단점: 높은 디지털 전력 (362 μm²)                  │  │
│  └──────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│  3. Adaptive AGC (제안 하이브리드 방식)                     │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ • Digital Bits: 트래픽 타입에 따라 적응              │  │
│  │   - lowpowersignal: 5-bit (전력 절약)               │  │
│  │   - highperformancesignal: 10-bit (정확도 보장)     │  │
│  │ • Gain: AGC 자동 조절 (STF 기반)                    │  │
│  │ • 장점: 전력과 성능의 균형                          │  │
│  │ • 차별점: 상황에 따라 최적 선택                     │  │
│  └──────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────┘

================================================================
           AGC 피드백 루프 상세
================================================================

초기 상태: Gain = 30 dB

신호 입력 (Noisy Signal)
    │
    ▼
┌───────────────────────────────────┐
│  STF 구간 추출 (2560 samples)     │
└───────┬───────────────────────────┘
        │
        ▼
┌───────────────────────────────────┐
│  현재 Gain으로 RF 증폭             │
│  LNA(15dB) + VGA(15dB) = 30dB     │
└───────┬───────────────────────────┘
        │
        ▼
┌───────────────────────────────────┐
│  STF Power 측정                    │
│  Power = 10*log10(mean(|sig|²))   │
│  예: 33.3 dBFS                     │
└───────┬───────────────────────────┘
        │
        ▼
┌───────────────────────────────────┐
│  목표 전력과 비교                  │
│  Target: -10 dBFS                 │
│  Error: -10 - 33.3 = -43.3 dB     │
└───────┬───────────────────────────┘
        │
        ▼
┌───────────────────────────────────┐
│  Gain 조정 결정                    │
│  |Error| > 2 dB? YES              │
│  Adjustment: -43.3 dB             │
│  Step 제한: ±3 dB                 │
│  → -3 dB 감소                     │
└───────┬───────────────────────────┘
        │
        ▼
┌───────────────────────────────────┐
│  새 Gain 적용                      │
│  New Gain = 30 - 3 = 27 dB        │
│  Range 체크: 10~50 dB OK          │
└───────┬───────────────────────────┘
        │
        ▼
┌───────────────────────────────────┐
│  ✅ Gain 고정 (27 dB)              │
│  이후 모든 처리에 이 gain 사용     │
└───────────────────────────────────┘
